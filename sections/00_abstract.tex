\begin{abstract}
Tool-augmented language agents are increasingly used for data analysis, where they query databases, execute code, retrieve documentation, and write reports from tool observations. Most reliability evaluations focus on visible failures such as crashes, timeouts, malformed outputs, or unavailable APIs. We study a less visible failure mode: the tool call succeeds and returns a well-formed, relevant observation, but the content is incorrect.

We introduce ToxicBench, a benchmark for measuring whether data agents blindly comply with such silent tool poisoning. ToxicBench wraps ordinary data-analysis tools with controlled perturbations that preserve normal execution, including corrupted numerical results, swapped labels and schema meanings, stale metadata, and biased retrieval evidence. We evaluate 34 numerical tasks and 24 semantic/schema tasks with full framework adapters for LangGraph, smolagents, PandasAI, DA-Agent, and AutoGen across three model families where practical. We also run a GPT-only 120-instance expanded cross-agent evaluation and a 120-instance LangGraph ReAct defense ablation. The results show a consistent gap between tool use and tool trust: agents that solve clean tasks often copy poisoned values or corrupted labels into final answers. Finally, we evaluate Guarded Verification, a lightweight wrapper that forms pre-tool expectations and independently verifies tool observations. On the expanded LangGraph ablation, it reduces exposure-conditioned blind compliance from 0.35 to 0.00 while improving poisoned-task success from 0.62 to 0.93.
\end{abstract}
