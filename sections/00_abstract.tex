Tool-augmented data agents can run a tool successfully and still reach a wrong conclusion when its output is silently corrupted. We introduce ToxicBench, a benchmark that inserts numerical, label, schema, and retrieval errors into otherwise successful tool responses. Each task pairs clean and poisoned runs with the same query and source data. The benchmark includes 120 single-table instances, a 13-task multi-table extension, and a cross-model suite with 34 numerical and 24 semantic/schema instances. In the expanded GPT evaluation, clean task success of 0.73--0.90 falls to 0.49--0.53 under poisoning. Trajectory metrics track whether agents adopt the poisoned answer, check the evidence, and recover the clean answer. A blinded audit measures how well the scorer captures these behaviors. On 120 LangGraph tasks, a second ordinary pass raises poisoned task success from 0.67 to 0.78. Adding generic expectations and a verification prompt does not improve on this control. Under repeated poisoning, agents can check the evidence and still adopt the poisoned conclusion. ToxicBench combines controlled corruptions, paired trajectories, and a common scoring protocol to study how agents use tool evidence and when further checks help.
