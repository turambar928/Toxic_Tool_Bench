\section{Related Work}
\label{sec:related}

Tool-use benchmarks evaluate API invocation \citep{qin2023toolllm,li2023apibank,patil2024gorilla}, while interactive and data-agent benchmarks assess task solving \citep{liu2023agentbench,zhou2023webarena,lei2025dacomp}. TRACE uses an evidence bank and LLM judges to assess trajectory efficiency, hallucination, and adaptivity \citep{kim2025trace}. ToxicBench shares this process perspective but distinguishes observation-supported answers from source-correct answers, tracking checking and final adoption.

Silent errors and recovery are studied by \emph{Tools Fail}, ToolBench-X, and PALADIN \citep{sun2024toolsfail,tian2026toolbenchx,vuddanti2025paladin}. ToolRobustBench pairs stage-aligned perturbations with deterministic, cascade-aware diagnosis within a tool-calling episode \citep{zheng2026toolrobustbench}. Adjacent threats include poisoned tool metadata \citep{li2026mcpitp,ye2026trustdesc}, retrieved content \citep{zou2024poisonedrag,liang2025saferag}, and financial tool data \citep{wu2026agentdrift}. ToxicBench follows subsequent checks and final adoption under one-shot and repeated observation corruption (Table~\ref{tab:closest-work}).

Data validation addresses source quality \citep{schelter2018automating,breck2019data,gu2025radar}; ToxicBench preserves sources as checking paths. Feedback and self-monitoring revise answers or tool use \citep{shinn2023reflexion,madaan2023selfrefine,zhou2024metarag,hamad2025toolcritic}, while calibration links confidence to tool decisions \citep{xuan2026confidence,subramani2025mice}. Our shared-budget-cap comparisons distinguish ordinary retries from explicit verification while varying recovery evidence.
