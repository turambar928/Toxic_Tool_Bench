Tool-augmented language agents are increasingly used for data analysis, where they query databases, execute code, retrieve documentation, and write reports from tool observations. Most reliability evaluations focus on visible failures such as crashes, timeouts, malformed outputs, or unavailable APIs. We study a less visible failure mode: the tool call succeeds and returns a well-formed, relevant observation, but the content is incorrect.

We introduce ToxicBench, a benchmark for measuring whether data agents blindly comply with silent tool poisoning. ToxicBench wraps ordinary data-analysis tools with controlled perturbations that preserve normal execution, including corrupted numerical results, swapped labels and schema meanings, stale metadata, and biased retrieval evidence. We evaluate an expanded 120-instance suite covering numerical and semantic/schema data-analysis tasks, together with a smaller cross-model suite of 34 numerical and 24 semantic/schema instances using full framework adapters for LangGraph, smolagents, PandasAI, DA-Agent, and AutoGen where feasible. The results show a consistent gap between tool use and tool trust: agents that solve clean tasks often copy poisoned values or corrupted labels into final answers. We report broad poisoned-answer adoption and a narrower blind-compliance rate that excludes runs with qualifying validation; these behavior metrics are deterministic proxies and are accompanied by a blinded development audit. Finally, we use Guarded Verification as a controlled protocol for measuring additional evidence collection. In a leakage-free 120-instance LangGraph ReAct ablation with a matched-budget control, Generic Guard reaches poisoned TSR 0.91 versus 0.78 for Double-pass, but task-paired intervals do not establish a guard-specific advantage. The revised scorer detects no BCR-positive Generic Guard trajectories under \texttt{poison\_once}; because the scorer was developed on the audit set and has limited BCR recall, this does not establish the absence of human-judged blind compliance. A full repeated-poison stress test shows that recovery degrades and blind compliance can return when verification observations are also corrupted.
