Tool-augmented data agents can execute a tool successfully and still reach a wrong conclusion when its output is corrupted. ToxicBench inserts numerical, label, schema, and retrieval errors into successful tool responses while keeping source data fixed. The release contains 120 synthetic single-table instances and 13 multi-table tasks; reference auditing retains 118 single-table instances for the revised main analysis. In the expanded GPT evaluation, clean task success of 0.92--0.99 falls to 0.59--0.67 under poisoning. Trajectory metrics distinguish adoption without checking from adoption after a fresh evidence action. Equal-budget two-route protocols separate ordinary retries from explicit verification prompts. A 240-trajectory human audit motivated a scoring revision, whose development recheck is reported separately from independent validation. Repeated poisoning exposes continued adoption after checking, including four cases confirmed in the original human audit. ToxicBench provides controlled diagnostic tasks and traceable scoring and reference corrections for studying when additional evidence helps agents recover.
