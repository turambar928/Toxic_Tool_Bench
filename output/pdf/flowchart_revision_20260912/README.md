## Suggested captions

Figure 1. Silent tool poisoning at the observation boundary. A successful computation identifies Store B as the highest-revenue store. The proxy changes only the returned entity label, preserving the value and output format. An agent that adopts the corrupted observation answers Store A, while the clean run answers Store B. Source data and tool execution remain unchanged.

Figure 2. ToxicBench evaluation and Guarded Verification. (a) Matched clean and poisoned runs are evaluated from their recorded trajectories; clean and poisoned oracles are used only by the evaluator. The reported suite sizes describe distinct evaluation configurations and should not be summed as disjoint instances. (b) Generic expectations precede primary execution, followed by fresh verification and evidence-gated finalization. Both routes share source data and a backend, so fresh execution does not establish source independence. Matched controls and repeated observation poisoning test the contribution and limits of verification.
