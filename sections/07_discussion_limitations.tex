\section{Conclusion and Limitations}
\label{sec:discussion}

ToxicBench measures how data agents respond when a successful tool call returns wrong evidence. Its paired tasks separate changes to returned observations from changes to source data. The verification experiments distinguish another attempt from an explicit request to check an earlier answer. Human evaluation supports the retry benefit over Base on the audited tasks and confirms adoption after checking under repeated poisoning. Together with the controlled evidence experiments, these results connect agent robustness to both the evidence available during checking and the answer ultimately selected.

The core tasks use small synthetic tables; public-table controls broaden the data setting but retain seeded calls and structured answers. Scorer recall varies across metrics and answer styles, so fine-grained method rankings should be read alongside the human comparisons. Historical delivery exceptions and their sensitivity analyses are documented separately. Intervals condition on the selected tasks and sources. Production workflows, naturally occurring error frequencies, and source-diverse verification are directions for future evaluation.
