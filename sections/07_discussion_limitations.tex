\section{Conclusion and Limitations}
\label{sec:discussion}

ToxicBench measures how data agents respond when a successful tool call returns wrong evidence. Its paired tasks separate changes to the returned observation from changes to source data. The verification experiments distinguish another attempt at the task from an explicit request to check an earlier answer. Later clean observations are common under one-shot poisoning; repeated poisoning exposes cases in which agents check evidence and still adopt the wrong conclusion, a behavior identified by both holdout annotators. Together, the task pairs, trace analysis, and human comparisons provide a common setting for testing how agents select and use evidence.

The current benchmark focuses on tabular tasks and controlled fault injection. Verification routes share source tables and backends, and adapters expose different tool boundaries. The held-out audit finds close agreement on evidence checking but larger differences in final-answer scoring and few BCR-positive cases. Its selected task subset does not estimate population-wide scorer accuracy; third-party adjudication remains pending. Task bootstrap intervals describe variation across sampled tasks, conditional on the label source. Extensions to live services, larger databases, and separate data sources would test broader forms of evidence dependence.
